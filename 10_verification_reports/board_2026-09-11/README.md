# KR260 실보드 검증 결과

2026-09-11, KR260 실보드, Ubuntu 24.04.2, kernel 6.8.0-1015-xilinx.
현재 프로젝트의 웹 UI에서 FPGA 재로딩 후 **전체 체인 검증** 버튼으로 실행했습니다.

| 검증 | 결과 |
| --- | --- |
| 4-IP FPGA 로딩 | 성공, 실제 클록 99,999,999 Hz |
| 22개 연산 AP_DONE | 모두 완료 |
| Layer 0 | 2,359,296 bytes, 불일치 0 |
| Head 1 | 4,320 bytes, 불일치 0 |
| Head 2 | 17,280 bytes, 불일치 0 |
| IP 연산 시간 합계 | 1,342.020 ms |
| 버퍼 준비와 비교를 포함한 검증 시간 | 3,281.149 ms |
| 호스트 및 보드 단위 테스트 | 각각 8개 통과 |

수치 정확도는 Layer 0과 두 최종 헤드의 전체 바이트를 검사했습니다.
중간 19개 출력의 개별 정답 비교나 카메라 입력의 실시간 인식 검증은 수행하지 않았습니다.
위 시간은 단일 저장 샘플의 실측이며, 카메라 FPS 또는 성능 상한을 뜻하지 않습니다.

원본 정답 head의 NCHW 데이터를 NHWC로 변환하여 비교합니다. 전달 파일의 이름에
NHWC라고 쓰여 있지만 실제 bytes는 NCHW라는 패키지 오류를 확인했습니다.
변환은 원본 exporter의 명세를 따르며, 결과를 보고 형식을 자동 선택하지 않습니다.
`verification.json`의 `full.checks.*.reference`에 출처와 원본 hash를 기록했습니다.

로딩 시 기본 `xmutil` DMA-BUF flag 잔류에 따른 커널 오류를 해결했고,
CMA DMA-BUF import/map을 담당하는 작은 kernel module을 추가했습니다.
설치 및 복구 방법은 [보드 앱 설명서](../../11_board_app/README.md)를 참고하세요.
